A follow-up to v1.1.2 that finishes its album-art fix: the cover helper no longer reads a redirect's body before following it. Nothing changes in how the widget looks or works.

**Update** with `omarchy plugin update crmne.mpris`, or install with `omarchy plugin add https://github.com/crmne/omarchy-mpris.git --enable --yes`.

## Fixed

- **A redirecting cover server can no longer grow the album-art helper without limit.** Python's standard library reads the whole body of a redirect response, however long, before following it. The helper now closes that response first, so only the final cover is read, within the 16 MiB limit introduced in v1.1.2. By @crmne.
